Kebijakan Privasi Joli Reels

Terakhir diperbarui: 10 November 2026

Joli Reels ("kami", "aplikasi") berkomitmen untuk melindungi privasi pengguna. Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, dan melindungi informasi Anda saat menggunakan aplikasi Joli Reels.

1. Informasi yang Kami Kumpulkan

  • Informasi Profil: Nama pengguna, usia, jenis kelamin, dan nomor telepon yang Anda masukkan secara sukarela di menu Profil.
  • Data Perangkat: ID Perangkat Unik (UUID) yang digunakan untuk menyimpan progres Anda (Poin, Koin, VIP) secara lokal dan di server kami.
  • Data Aktivitas: Riwayat tontonan, daftar drama yang disukai, dan interaksi Anda di dalam aplikasi.
  • Advertising ID: Melalui Google AdMob, kami dapat mengakses ID Perangkat untuk menayangkan iklan yang relevan.

2. Penggunaan Data

Kami menggunakan data Anda untuk:

  • Menyinkronkan saldo Poin, Koin, dan status VIP Anda.
  • Menampilkan konten drama yang sesuai dengan preferensi Anda.
  • Menayangkan iklan dari Google AdMob (baik personal maupun non-personal).
  • Meningkatkan kualitas layanan dan fitur aplikasi.

3. Pihak Ketiga (Third-Party Services)

Aplikasi ini menggunakan layanan pihak ketiga yang memiliki kebijakan privasi sendiri:

  • Supabase: Digunakan untuk menyimpan database profil pengguna secara aman (terenkripsi).
  • Google AdMob: Digunakan untuk menampilkan iklan. Google dapat menggunakan Advertising ID untuk personalisasi iklan. Anda dapat menonaktifkan personalisasi di menu Tentang > Iklan Dipersonalisasi.

4. Penyimpanan dan Keamanan Data

Data Anda disimpan secara aman di server Supabase. Kami tidak menjual atau membagikan data pribadi Anda kepada pihak ketiga untuk tujuan pemasaran tanpa izin Anda.

5. Penghapusan Akun dan Data

Anda memiliki hak penuh untuk menghapus akun Anda. Anda dapat menghapus seluruh data Anda secara permanen dengan menekan tombol "Hapus Akun" di dalam aplikasi (Menu Profil > Hapus Akun). Setelah dihapus, data tidak dapat dikembalikan.

6. Privasi Anak-anak

Aplikasi ini tidak ditujukan untuk anak-anak di bawah usia 13 tahun. Kami tidak dengan sengaja mengumpulkan data dari anak-anak.
